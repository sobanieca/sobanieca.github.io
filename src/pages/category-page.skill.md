categoryPage - the screen of one category: its articles as cards, with an ascending/descending sort toggle.

```js
import { categoryPage } from './pages/category-page.js'

categoryPage('build-anywhere')
```

| Argument | Type   | Notes                                               |
| -------- | ------ | --------------------------------------------------- |
| `slug`   | string | the folder name under `articles/`; required, exists |

- `src/content/routes.js` (generated by build.js) binds one per category node of the map.
- The sort is the state `blog.sortDescending`, owned by the screen; it resets on each visit.
- Articles sort by the numeric prefix of their file name.
